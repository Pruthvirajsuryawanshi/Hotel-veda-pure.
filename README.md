# Hotel Veda Pure

A small brochure website for Hotel Veda Group, showcasing vegetarian dining locations and lodging.

## Project Structure

- `index.html` — main homepage for Hotel Veda Group
- `veda-pure-veg.html` — restaurant page for Veda Pure Veg
- `vedant-pure-veg.html` — restaurant page for Vedant Pure Veg
- `sai-shraddha-lodging.html` — lodging page for Sai Shraddha Lodging
- `styles/main.css` — shared site styling and responsive layout
- `scripts/main.js` — shared interactive behavior for navigation, theme toggle, and mobile support
- `assets/` — logo and favicon assets
- `images/` — property and menu photos used on the site

## Features

- responsive layout optimized for mobile and desktop
- mobile navigation menu with expand/collapse behavior
- theme toggle button for light/dark appearance
- gallery and card-based content sections
- shared footer with current year and contact links

## Usage

1. Open `index.html` in a browser to view the homepage.
2. Navigate to the restaurant and lodging pages using the in-site menu.
3. Update images and contact details in the HTML files as needed.

## Notes

- The site is built with static HTML, CSS, and JavaScript.
- No build tools are required; the project works by opening the HTML files directly.
- To customize content, edit the corresponding HTML page and update `styles/main.css` or `scripts/main.js`.
